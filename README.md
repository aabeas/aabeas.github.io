## Overview

This is the personal website for showcasing projects, interests, and blog posts. The site is built using HTML, CSS, and JavaScript and hosted on GitHub Pages.

## Features

- **Responsive Design**: Built with Bootstrap for seamless viewing on all devices.
- **Carousel**: A dynamic image carousel on the homepage.
- **Custom Styling**: Includes custom CSS for unique branding.
- **Blog Section**: Highlights recent blog posts and articles.
- **Projects Section**: Displays featured projects with descriptions and links.

## Technologies Used

- **HTML5**: For semantic structure.
- **CSS3**: Custom styles and Bootstrap framework.
- **Bootstrap 5.3**: For responsive design and prebuilt components.
- **JavaScript**: For dynamic functionality (e.g., carousel behavior).
